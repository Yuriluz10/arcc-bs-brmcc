# Busca e Salvamento — ARCC-BS & BRMCC

Landing page de divulgação do ARCC-BS (Centro de Coordenação de Busca e Salvamento Aeronáutico de Brasília) e do BRMCC (Centro Brasileiro de Controle de Missão COSPAS-SARSAT) para a feira internacional de aviação em Brasília.

Página: https://yuriluz10.github.io/arcc-bs-brmcc/

Para editar telefones e links, altere o bloco `CONFIG` no início do `index.html`.
